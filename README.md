# Zerocoder_Python — учебные проекты курса Python

Работы курса «Python-разработка» (Zerocoder): 45 папок — от первых HTML-страниц до Django-приложений, Telegram-ботов и итогового проекта.

## Главное: итоговый проект

**[TaskMentor](taskmentor/)** — CRM для коучей и наставников на Django 5.2. Управление клиентами, задачи с приоритетами, цели с автопрогрессом, дневник настроения, вход через Google OAuth, синхронизация задач с Google Calendar, Web Push и Firebase Cloud Messaging, адаптивный перенос просрочек, 6 миграций, 81 тест.

Это единственная работа с полноценной документацией: [taskmentor/README.md](taskmentor/README.md) — установка, переменные окружения, деплой, описание слоя сервисов.

## Как запустить

### Итоговый проект

Подробно — в [taskmentor/README.md](taskmentor/README.md). Кратко:

```bash
cd taskmentor
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

По умолчанию используется SQLite, внешняя база не нужна.

### Django-проекты из папок dj*

```bash
cd dj04
pip install django
python manage.py migrate
python manage.py runserver
```

### Flask-проекты из папок vd*

```bash
cd vd05
pip install flask
python vd05.py
```

Для `vd07` дополнительно нужен Flask-SQLAlchemy, для `vd08` — `requests`.

### Telegram-боты

В каждой папке нужен токен бота — в `.env` или `config.py`. Ключей в репозитории нет, без токена бот не запустится.

### Скрипты и задачи

Файлы в `az*`, `ob*`, `od*` запускаются напрямую:

```bash
python az01/az01_1.py
```

Для `az01` и `az03` нужны CSV-файлы из тех же папок. Для `og05` и `ob05` — `pygame`.

## Замечания по структуре

Папки названы кодами заданий (`az01`, `ob03`, `vd08`) — удобно при сдаче, нечитаемо со стороны. Коды оставлены как есть, чтобы не терять связь с заданиями; расшифровка — в таблицах выше.

`requirements.txt` верхнего уровня нет: у каждого проекта свои зависимости, указаны в файлах внутри папок.
